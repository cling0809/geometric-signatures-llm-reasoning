This compact bundle is the exact post-selection report for the complete
predeclared Qwen2.5-1.5B-Instruct validation family.  It was produced only
after all eight method directories completed their 16-cell layer/alpha grids on
GSM8K IDs 100--199.  The frozen selection file had already been written before
any locked GSM8K generation was opened.

## Contents

- `validation_complete_summary.csv`: all 128 predeclared validation cells
  (eight methods times four layers times four alphas), including behavior-guard
  status and the one frozen selected cell per method.
- `validation_selected_rows.tex`: a compact appendix-facing rendering of the
  eight selected cells; it is not a locked-test table.
- `validation_family_report_manifest.json`: selection hash, input
  `summary.csv` hashes, selected decisions, and output hashes.

The report generator recomputes every recorded selection from the frozen rule
and refuses any source `summary.csv` whose SHA-256 differs from the immutable
selection artifact.  It was generated by
`/scripts/revision_build_validation_family_report.py`.

## Interpretation boundary

The common validation baseline accuracy is 0.58.  The selected validation gains
are selection-stage values only; they cannot support a CrossSteer performance
claim or a relative baseline ranking.  **Because the whole v1 family is
superseded (see the banner above), these numbers must not be used for any
revised claim.**  The corrected v2 family provides the only admissible
selection-stage and locked evidence.

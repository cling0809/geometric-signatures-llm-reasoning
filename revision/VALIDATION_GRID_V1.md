# Frozen GSM8K Steering Validation Grid V1

**Status:** Historical frozen protocol; the validation and locked stages have completed.  Final outcomes are reported in `revision/FINAL_CLAIM_AUDIT.md`, `revision/REVIEWER_COMMENT_TRACKER.md`, and the mirrored evidence manifests.  This document records the protocol, not a pending run.

**Historical protocol note:** Declared before validation generation.  This document controlled the
first fair comparison between the train-only `crosssteer_source` direction and
the `target_calibrated` direction.  The later CAA/ActAdd/sparse comparison used
the same declared selection budget and is now reported in the complete frozen
family evidence.

## Fixed data roles

| Role | GSM8K IDs | Use |
|---|---:|---|
| Source training | 0--99 | Construct both directions only. |
| Validation | 100--199 | Select one layer/alpha for each method. |
| Locked in-domain test | 200--299 | Not inspected or generated by this grid. |
| Replication reserve | 300--499 | Not used in this grid. |

## Fixed target and generation protocol

- Target: `Qwen/Qwen2.5-1.5B-Instruct`.
- Prompt: exact shared revision GSM8K prompt saved in the run manifest.
- Decoding: greedy, `max_new_tokens=512`, no sampling, no beam search.
- Injection: `position_mode=decode_last`; prompt prefill is untouched.
- Schedule: constant.  Long-context schedules are a separate predeclared study.
- Direction normalization: RMS 1 at its injection layer.

## Equal method budget

Each method evaluates the same 16 validation cells:

- layers: `8, 14, 20, 24` (approximately 29%, 50%, 71%, 86% of 28 transformer
  blocks);
- alphas: `0.025, 0.05, 0.10, 0.20` after RMS normalization.

The alpha range is a declared fraction of a unit-RMS residual perturbation; it
is not converted from historical raw-vector alpha values.  The historical raw
alpha sweep is excluded from this decision.

Methods in this first grid:

1. `crosssteer_source`: Qwen-Math source trajectory direction;
2. `target_calibrated`: Qwen-Instruct target trajectory direction.

CAA, ActAdd, a matched-norm random-direction control, an exact sign-reversed
CrossSteer direction control, an SAE-space sparse activation baseline, and the
predeclared 10% coordinate-sparse CAA ablation will later run this same grid,
without changing its layer/alpha budget. Their
vectors are built from source IDs 0--99 only: CAA uses multiple same-question
correct/incorrect prompt-final pairs; ActAdd uses one SHA-256-selected pair;
the random control is one fixed-seed (`11241`) isotropic Gaussian vector matched
to CrossSteer's raw L2 norm and shape; the negative-direction control is the
exact sign reversal of the frozen CrossSteer source vector; the SAE is trained
without correctness
labels on fixed relative-progress target states and selects sparse features from
the same-question pairs; the coordinate-sparse vector remains explicitly not
presented as an SAE method. The random control is not seed-swept or reported as
the maximum over seeds.

## Selection rule

For each method separately:

1. Exclude a cell if its mean repeated-4-gram fraction rises by more than 0.05
   absolute over the unsteered baseline **or** its mean output-token count is
   more than 1.5 times the baseline mean.
2. Among remaining cells choose maximum validation accuracy.
3. Exact ties are broken in this fixed order: smaller alpha, lower repetition,
   shorter mean output, lower layer index.
4. If no cell passes the behavior guard, the method is declared ineligible and
   is not represented as a positive locked-test intervention.

Before selection across methods, the selector also verifies that every run
shares the same target/prompt/decoding manifest and that its independently
regenerated no-steering baseline rows are exactly identical on every validation
problem.  A mismatch refuses selection rather than comparing methods against
different baselines.

The selected cell and all validation rows are saved before any locked-set
generation.  The locked test is evaluated exactly once per eligible method,
without an alpha, layer, sign or schedule retry.
